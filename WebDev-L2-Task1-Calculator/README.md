# 🧮 Web Development Level 2 — Task 1

## Calculator

A simple and interactive calculator built using **HTML, CSS, and JavaScript** as part of the OASIS INFOBYTE Web Development Internship tasks.

### ✨ Features

* Addition
* Subtraction
* Multiplication
* Division
* Decimal calculations
* Clear button
* Delete button
* Interactive calculator interface
* Responsive design

### 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

### 📂 Project Structure

```text
WebDev-L2-Task1-Calculator/
│
├── index.html
├── style.css
└── script.js
```

### 🚀 How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start using the calculator.
